คำถาม client-server :

ตอนที่เปิดเว็บไซต์จากเครื่องของตัวเอง จะมี Client เกิดขึ้นอยู่แล้ว
คือเว็บเบราว์เซอร์ที่เราใช้เปิดเว็บไซต์ ส่วน Server ยังไม่เกิดขึ้น

เพราะ เราเปิดไฟล์ HTML ที่อยู่ในเครื่องของเราเองโดยตรง ไม่ได้ดึงข้อมูลจาก Server ภายนอก

How I Built It

งานนี้ผมได้ทำตามขั้นตอนหลักๆดังนี้

  1. สร้างโฟลเดอร์งาน A1project7562
  2. สร้างไฟล์ index.html และ css/style.css
  3. เขียนโค้ด HTML ใส่เนื้อหาที่กำหนดให้
  4. เขียนโค้ด CSS ตกแต่งเว็บไซต์

โดยผมใช้ vs code เป็นเครื่องมือในการเขียนโค้ด
ส่วนนี้คือเว็บไซต์ที่ผมใช้ศึกษาเพิ่ม: w3schools
